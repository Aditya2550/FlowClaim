# Frontend (React + Vite)

Feature-based modular frontend for reimbursement workflows.

## Highlights

- Setup wizard UI (bootstrap endpoint support)
- Multi-currency live conversion badge
- OCR drag-and-drop zone with scanner animation
- Approval quick-decision feed + breadcrumbs support
- Rule canvas for percentage/specific/hybrid modes
- Real-time notifications with WebSocket client

## Run

1. npm install
2. npm run dev
